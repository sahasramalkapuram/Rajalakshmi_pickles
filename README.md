# Rajalakshmi Pickles 🫙✨

An authentic, human-designed e-commerce web application crafted for a traditional homemade pickle business. 

## 🚀 Features
- **Traditional Aesthetic:** Warm terracotta and deep forest green palette (no generic templates).
- **Product Catalog & Filters:** Browse veg and non-veg pickles with live search and detailed ingredient notes.
- **Secure Owner Portal:** Protected by a master PIN (`....`) to add/remove products, change prices, toggle stock, and manage customer orders.
- **Flexible Payments:** Integrated UPI QR code UTR verification, Razorpay online payments, and Cash on Delivery (COD).
- **Customer Order Tracking:** Remembers repeat customers and lets them view their past order history.

## 🛠️ Tech Stack
- HTML5 & JavaScript (Vanilla)
- Tailwind CSS (via CDN)
- LocalStorage for client-side persistence
